# Quick Start Guide - Medical Store Application

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies (One-time)
```bash
pip install flask flask-cors pyjwt
```

### Step 2: Run the Server
```bash
cd "c:\Users\parth\OneDrive\Documents\sigma web dev\medical application"
python app.py
```

### Step 3: Open in Browser
```
http://localhost:5000
```

## 📱 First Time Setup

1. **Create Account**
   - Click "Sign up here"
   - Username: demo (or your choice)
   - Password: demo123 (or your choice)
   - Click "Sign Up"

2. **Login**
   - Enter your username & password
   - Click "Login"

3. **Explore Tabs**
   - **Dashboard**: View statistics and charts
   - **Payments**: Add and manage payments
   - **Medicines**: Manage inventory
   - **Patients**: Manage patient records

## 💡 Quick Actions

### Add Your First Medicine
1. Go to "Medicines" tab
2. Fill in:
   - Name: Paracetamol
   - Category: Tablet
   - Price: 50
   - Stock: 100
3. Click "Add Medicine"

### Add Your First Patient
1. Go to "Patients" tab
2. Fill in:
   - Name: John Doe
   - Phone: 9876543210
3. Click "Add Patient"

### Record Your First Payment
1. Go to "Payments" tab
2. Start typing in "Medicine Name" - select Paracetamol
3. Price auto-fills!
4. Enter patient name, quantity, payment mode
5. Click "Add Payment"
